	Every file in this directory is vendored unmodified from the Kenney
	"Game Assets All-in-1" bundle (3.6.0), keeping its original filename so it
	can be traced back to the pack it came from. Only the files the game
	actually plays are copied here — see `res://game/sfx.gd` for the
	event -> file table that is the sole consumer of all of them.

	                              leaving the cob
