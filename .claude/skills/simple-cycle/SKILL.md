---
name: simple-cycle
description: A simple cycle of tasks, with a single task that can be completed multiple times. This is a good starting point for learning how to use Claude's skills. This skill should not be updated by AI.
---

1. Look at the top beads and select 1 you believe is most important.
2. Think critically about how to resolve it. Do not treat it as a mandatory feature or requirement. Consider whether the best way to approach it.
3. Look for unncessary python tools, tests, and code generations tools, and remove them if they're not needed or they're adding a bunch of unncessary work.
4. Implement and resolve bead.

- practice small and frequent commits, such as arlo commit notation.
- refactor files greater than 500 lines of code into smaller files using object oriented design principles
- update tests to reflect refactoring and file patterns
- Ensure all new code is covered by unit tests and run tests correct any issues
- Ensure production code is mostly comment-free because comments should live on the unit tests.
- Drive the game through the devtools bridge (see run-the-game-and-drive-it skill) to test gameplay, correct any issues

5. When you're done, reflect on any skill or plugin used, reflect on its output and its usage, and
   suggest concrete improvements to that skill. If the suggestion is concrete enough, go ahead and proceed with implementing the concrete improvement.
6. When you're done, reflect on this repo and it's claude harness. If there is anything that could simplify or improve the repo, go ahead and implement it.
7. Relfect on the session, create any skills you WISH you had during the run that would be useful for future runs. Keep them simple.
8. At the end, give me an extremely short list of things implemented by all of the above.
