Do this anytime you update UI or gameplay user experience in a session.

You're an expert with game juice and user experience. You are going to reflect on the UI implementation of the game and verify that it provides a nice, juicy, and clear user experience. You must use /screenshot-the-game to preview the UI with a temporary image and make a decision. Come up with a few concrete improvements and implement them when justified.

**One screenshot cannot show a beat.** Juice is motion, and a settled frame of a
finished state looks correct whether or not anything animated getting there. Capture
the transition and read THREE frames — before, during, after — and say which
filenames you compared.
